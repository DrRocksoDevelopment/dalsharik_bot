## Этап 8a — Управление вопросами (горячая перезагрузка + модерация)

Механизм обновления пула вопросов без перезапуска.

Задачи:

1. `src/game/question-validator.ts` — структурная валидация по §40 (поля, типы, категории, сложность 1–5, ≥4 варианта, correctAnswer ∈ вариантов, уникальные id, explanation, sources, уникальность текстов).
2. `src/game/question-reloader.ts` — следит за `questions.json` (fs.watch + тик 60с):
   - валидный файл → применяется в движок (`engine.updatePool`), последняя хорошая версия пишется в `questions_backup.json`;
   - битый JSON / невалидные вопросы → откат на последнюю хорошую версию (атомарно).
3. Модерация: новые вопросы кладутся в `data/questions_pending.json`; бот уведомляет админа (`BOT_ADMIN_ID`) сообщением с inline-кнопками ✅ Одобрить / 🚫 Отклонить.
4. Команда `/pending` — список ожидающих (только админ).
5. Одобренный вопрос валидируется и атомарно добавляется в активный пул (движок подхватывает сразу).

Выходной критерий: правка вопросов на лету без рестарта; повреждённый JSON не ломает пул; новые вопросы попадают в игру только после одобрения админа. ✓

## Этап 10 — Выбор вопросов и сложность от времени суток

Соответствует §18 (random weighted selection) и §17 (адаптация).

Задачи:

1. `src/game/time-of-day.ts` — окна «час → диапазон сложности» (утро 1–2, день 2–4, вечер 3–5, ночь 2–4); локальный час = UTC + оффсет чата (всегда через `getUTCHours()`, без зависимости от пояса сервера); пересечение с диапазоном чата (пусто → диапазон чата). ✓
2. Поле `timezoneOffsetMinutes` в `ChatConfig` (дефолт 180 = Москва), бэкфилл для существующих записей. ✓
3. Команда `/set_timezone ±Ч[:ММ]` (−12…+14). ✓
4. Переработка `InMemoryQuestionEngine.selectNext`: взвешенная рандомизация — вес категории `1/(1+использования в последних 5)`, вес сложности `1/(1+0.5×|difficulty−цель|)`. ✓
5. Тесты: engine (фильтры, время суток, балансировка, bias), timezone (парсинг, локальный час). ✓

Выходной критерий: вопросы не повторяют категории подряд, сложность адаптируется к времени суток группы, пояс настраивается per-chat. ✓
