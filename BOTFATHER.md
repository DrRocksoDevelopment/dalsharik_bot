# Заполнение в BotFather

Инструкция для настройки бота через [@BotFather](https://t.me/BotFather).

## 1. Имя и юзернейм

- `/setname` — имя бота, например: `Дальшарик — викторина «Что было дальше?»`
- `/setusername` — юзернейм (латиницей), например: `dalsharik_bot`

## 2. Короткое описание (About) — `/setabouttext`

> Викторина по реальным историческим и научным событиям: угадай, что было дальше. Групповые раунды, рейтинги, серии и сложность под время суток.

(до 140 символов)

## 3. Полное описание — `/setdescription`

> Групповая викторина «Что было дальше?»: бот показывает реальное событие (история, наука, технологии, бизнес, культура, география), а игроки угадывают, что произошло дальше. После раунда — итоги: очки, скорость реакции, серии. Сложность автоматически подстраивается под время суток группы. Есть рейтинги группы и общий рейтинг.

(до 512 символов)

## 4. Команды — `/setcommands`

Вставьте список целиком (формат: `команда - описание`, разделитель «-»):

```
start - Запустить игру в группе (админ)
stop - Остановить игру в группе (админ)
help - Справка по командам
config - Конфигурация чата (суперадмин)
set_answer_window - Окно ответов, секунды (админ)
set_interval - Интервал между вопросами (админ)
set_types - Типы вопросов через запятую (админ)
set_difficulty - Диапазон сложности 1-5 (админ)
set_timezone - Часовой пояс группы (админ)
top - Топ группы
top_global - Общий рейтинг
stats - Личная статистика
metrics - Метрики бота (суперадмин)
import - Импорт вопросов из папки (суперадмин)
pending - Модерация новых вопросов (суперадмин)
```

## 5. Privacy mode — `/setprivacy`

Можно оставить **включённой**. Бот не нуждается в чтении сообщений: вопросы
публикуются через нативные Telegram-опросы, ответы приходят как `poll_answer`,
команды обрабатываются сами по себе.

## 6. Прочее

- `/setinline` — выключить (inline-режим не используется).
- `/setuserpic` — аватар бота (логотип викторины).
- `/setjoingroups` — разрешить добавление в группы (обязательно включено).
- `/setcommands` можно повторить в любой момент после добавления новых команд.
